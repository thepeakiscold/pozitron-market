`iyzico-ile-ode.svg`: Beyaz Zeminde Yatay Kullanım (TR) paketinden değiştirilmeden alınmıştır.
`payment-logos.svg`: resmi iyzico logo paketindeki `footer_iyzico_ile_ode/Colored/logo_band_colored.svg`, değiştirilmeden alınmıştır. iyzico, Visa ve Mastercard işaretlerini içerir.

Logoların bulunması ödeme entegrasyonunun veya başvuru onayının tamamlandığı anlamına gelmez.

`paytr.png`: https://www.paytr.com/wp-content/uploads/logo-1.png adresinden değiştirilmeden alınmıştır. Yalnızca ödeme sağlayıcısı alanında, gelecek hizmet durumu açıkça belirtilerek kullanılır. Üretime geçişte PayTR'nin işyerine bildirdiği logo yerleşimi uygulanmalıdır.
